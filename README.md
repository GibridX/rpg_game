# TextRPG - Текстовая RPG игра

![Gameplay Screenshot](./TextRPG/docs/media/screenshots/Снимок%20экрана%20от%202025-10-01%2017-20-37.png)

*Подземелья, сражения и сокровища в консольной RPG*

## Описание проекта

Текстовая RPG игра в жанре rogue-like с консольным интерфесом. Игрок исследует генерируемые уровни, сражается с врагами, собирает предметы и прокачивает персонажа.

**Текущее состояние**: Рабочий прототип (требуется рефакторинг кода)

## Установка и запуск

### Требования
- .NET 8.0
- Windows/Linux/macOS с поддержкой консоли

### Сборка и запуск
```bash
# Клонирование репозитория
git clone https://github.com/yourusername/TextRPG.git
cd TextRPG

# Сборка проекта
dotnet build

# Запуск
dotnet run
```
